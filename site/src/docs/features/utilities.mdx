dreamland core also provides some more miscallaneous sugar to make code look better.

## Reactive strings: usestr

You can use the `use` function as a template tag function to create string pointers:

```tsx
<div>
	<input placeholder={use`Hello, ${this.name}!`} />
</div>
```

This is useful for text or class strings which need to be recalculated.

## Delegates

Delegates make it easier to call functions on child components, which would instead require exposing a function on `this` and getting a reference to the component's state.
They are functions which have a `listen` function on them.

For example, you can create a delegate in the parent component and then pass it to the child component, which then calls `listen` on it:

```tsx
import { createDelegate } from "dreamland/core";

function Ripples(this: FC<{ create: Delegate<MouseEvent> }>) {
	this.cx.mount = () => {
		this.create.listen((e: MouseEvent) => {
			// create ripple...
		});
	};

	return <div />;
};

function Button(this: FC) {
	let ripple = createDelegate<MouseEvent>();

	return (
		<div on:pointerdown={ripple}>
			<Ripples create={ripple} />
		</div>
	);
};
```
