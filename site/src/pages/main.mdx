## Flexible and incremental

dreamland has **no virtual DOM**, allowing for easy integration with vanilla JS libraries and the browser's DOM APIs.
It's easy to incrementally add dreamland to existing vanilla JS codebases because you can immediately attach dreamland components to the DOM.
